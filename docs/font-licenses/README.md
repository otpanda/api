# Embedded fonts

The signup fallback embeds Bricolage Grotesque for display text and Figtree for body text. Both use SIL Open Font License 1.1; copyright and license notices are included here.

The embedded WOFF2 subsets cover Latin-1 and Latin Extended-A. Other scripts use system fallback fonts. Font data is embedded in src/brand-fonts.js, not fetched from an external font service.
